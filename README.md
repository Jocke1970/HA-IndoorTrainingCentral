# HA-IndoorTrainingCentral

Home Assistant integration for indoor cycling (Tacx FLUX S), rowing (Top Sport WP5000), treadmills (FTMS / HomeFitnessCode) and Wahoo HEADWIND fan control.

**No stable release has been published.** The main branch contains Marketplace registration metadata only, not a runnable integration.

## Install the beta through Home Assistant Marketplace

1. Open **Settings → Marketplace → Add from link**.
2. Add `https://github.com/Jocke1970/HA-IndoorTrainingCentral` as type **Integration**.
3. Enable **Pre-release** and install the newest published `2026.11.0bN` release.
4. Restart HA when prompted. Existing integration entries retain their internal domain `homefitnesscode`.

The `dev` branch is for development, `beta` is the Marketplace test channel, and `main` will contain a stable version only after hardware verification.
