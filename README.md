# HomeFitnessCode

Home Assistant Bluetooth FTMS / HomeFitnessCode integration for treadmills, indoor bike trainers and rowing machines.

**There is no stable release yet.** This default branch contains **Marketplace registration metadata only**, not a runnable integration. Do not install the default branch.

## Install beta using Home Assistant Marketplace

1. Settings → Marketplace → Add from link.
2. Add `https://github.com/Jocke1970/HomeFitnessCode` as type **Integration**.
3. Enable **Pre-release** for HomeFitnessCode.
4. Install `2026.11.0b1` or the newest explicitly published beta release.

Beta releases are built from the `beta` branch. The `dev` branch is for development only. No stable code is promoted to `main` until hardware testing is completed.

[Beta release notes](https://github.com/Jocke1970/HomeFitnessCode/releases/tag/2026.11.0b1)
